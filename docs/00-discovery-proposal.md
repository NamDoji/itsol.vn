## 1. Phân tích website ITSOL hiện tại

Nguồn tham khảo:

- ITSOL/beta ITSOL: https://beta.itsol.vn/
- ITSOL public pages: https://itsol.vn/
- ITSOL introduction PDF 2019: https://itsol.vn/wp-content/uploads/2020/02/ITSOL_Introduction_en_2019.pdf

Nhận định:

- Định vị cốt lõi đã có: **Talent Trusted Partner**, **IT Solution & Resources Company**.
- Nội dung năng lực chính đã đúng hướng: **IT Staffing & Placement**, **IT/Software Outsourcing**, **IT Solution Consulting**.
- Điểm mạnh nên giữ:
  - ITSOL là công ty chuyên về nguồn lực IT, không chỉ là software house.
  - Có câu chuyện phù hợp với nhu cầu thị trường: thiếu hụt nhân lực IT, doanh nghiệp cần team nhanh, cần đối tác công nghệ linh hoạt.
  - Có thể mở rộng sang AI/Digital Transformation mà không làm mất gốc staffing/outsourcing.
- Vấn đề hiện tại:
  - Website cũ thiếu cảm giác corporate hiện đại, chưa thể hiện rõ năng lực AI/ODC/dedicated team.
  - Nội dung blog/category có dấu hiệu lẫn nội dung không liên quan, ảnh hưởng niềm tin và SEO.
  - CTA chưa đủ mạnh cho lead B2B: Request Talent, Send JD, Start a Project, Book Consultation.
  - Chưa thấy hệ thống CMS/admin để cập nhật banner, dịch vụ, case study, blog, job, contact.

Kết luận:

ITSOL nên được tái định vị thành **AI-era IT Talent & Technology Partner**: vừa cung cấp nhân lực IT đáng tin cậy, vừa triển khai phần mềm/sản phẩm/AI solutions cho doanh nghiệp.

## 5. Cấu trúc frontend/backend đề xuất

### Khuyến nghị công nghệ

Giai đoạn 1 nên dùng:

- Next.js + TypeScript + Tailwind CSS
- Next.js API routes
- SQLite cho local/MVP
- Prisma ORM nếu Cuong duyệt cài package
- Admin dashboard tích hợp trong Next.js

Giai đoạn production có thể nâng cấp:

- PostgreSQL
- Auth.js/NextAuth hoặc custom auth hardening
- S3-compatible storage cho media
- Vercel/Node server/VPS deployment

Lý do:

- Một codebase dễ triển khai.
- Nhanh có admin/CMS.
- SQLite đủ cho giai đoạn đầu.
- Dễ migrate PostgreSQL khi cần.

## 9. Đề xuất triển khai sau khi Cuong duyệt

### Phase 1 - Corporate MVP

- Public website đầy đủ các trang chính.
- Admin login cơ bản.
- CRUD services, case studies, blog, jobs.
- Contact form và request talent form.
- Seed data song ngữ.
- SQLite local.

### Phase 2 - Business-ready

- Media upload.
- SEO metadata editor.
- Preview/draft/publish workflow.
- PostgreSQL migration.
- Email notification cho contact/talent request.
- Security hardening.

### Phase 3 - Growth

- Multi-market landing pages.
- Analytics dashboard.
- AI chatbot hoặc AI lead qualification.
- Talent pool mini CRM.
